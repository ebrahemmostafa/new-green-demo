# Finca Wedding Template - Source Code

## Overview
Full source code for the Finca wedding invitation template.
Site: https://finca-demo.thedigitalyes.com/

## Features
- Rustic finca/farmhouse theme
- Video intro animation
- Background music
- English-only content
- Illustrations (champagne, party, rings)
- RSVP with confirmation animation
- Confetti effect

## Directory Structure
- index.html        - Main page (local asset paths)
- css/             - Stylesheets (with .beautified.css)
- js/              - JavaScript (with .beautified.js)
- assets/images/   - Illustrations, watermark, poster
- assets/audio/    - Background music
- assets/video/    - Intro video, RSVP confirmation
- assets/fonts/    - Font files (if any)
